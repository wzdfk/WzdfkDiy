# 使用帮助

## 1. 如何 DIY

1. **定义风格**：在顶栏输入框写一句话（如「蓝色工业风，硬边印刷感」），按回车或点「新建风格」。
2. **多轮打磨**：在左侧对话区继续提要求，如「再柔和一点」「主色改成 #5b7c89」。每次修改会在中间显示基准 / 新预览对比，点「接受」生效，「拒绝」回退。
3. **存档**：调好后点顶栏「存档」保存到 MySQL，起名后可在「档案」里随时加载回来。
4. **配置 AI**（可选）：点左下角「设置」填入厂商与 API Key。未配置时系统用内置风格词典兜底，核心流程照常可用。

## 2. 如何导出

1. 点顶栏「导出产物包」，下载 zip。
2. 包内 8 个文件，**复刻只需前 4 个**：

| 文件 | 作用 |
| --- | --- |
| `STYLE_PROMPT.md` | 风格规范正文，AI 首要读它 |
| `base.css` | 设计令牌：`:root` 里定义的全部变量 |
| `style.css` | 组件样式规则，扩展新组件照此写 |
| `preview.html` | 组件结构与类名示例 |

其余 `manifest.json`（校验）、`raw-llm.json`（原始响应）、`source-conversation.json`（对话历史）、`CHANGELOG.md`（变更记录）是溯源文件，复刻时不用给 AI。

## 3. 导出后如何复刻

1. 开一个**全新 AI 会话**，把上面 4 个文件一起发进去，不给其他上下文。
2. 附上要求，例如：

> 以上是我的风格规范。请按同一套变量与签名新增一个 Switch 组件，生成单个 HTML 演示。所有样式必须引用 `base.css` 里已有的变量（变量名和前缀以该文件为准），不要写死颜色、圆角、阴影等具体值。

3. 核对 AI 产物时，**以 `STYLE_PROMPT.md` 描述的风格签名为准**，逐项检查：圆角策略、投影类型、动效曲线、焦点样式、背景与材质等是否与该文档一致；再检查新增样式是否全部引用 `base.css` 中真实存在的变量，没有写死值或自造变量名。

注：当前导出为 V2 格式，没有独立的 `style.json`；`base.css` 里的 `:root` 变量就是令牌源。每套产物的变量前缀和风格签名都不同（如折角/实色投影/虚线焦点环只属于 FOLD 那一套），不要套用别的风格标准。
