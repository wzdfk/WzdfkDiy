WHAT IT DOES

从一句话，到可复刻的风格资产

不是生成一张示意图，而是生成一组能被 AI 和工程共同使用的风格文件。

01

一句话生成

输入「蓝白玻璃质感，柔和投影」这类描述，即刻得到完整风格产物包。

02

多轮微调

在对话里说「再柔和一点」「主色改成 #5b7c89」，改动映射到具体视觉维度。

03

所见即所导

中间预览注入的就是产物包里的真实 CSS，不是另画一张展示图。

04

可复刻交付

导出的 zip 交给任意新 AI 会话，按 Prompt 和 CSS 变量扩展新组件。

05

无 AI 也能用

未配置模型时走内置风格词典，核心流程照常可用。

06

本地优先

Key 只存浏览器，产物导出到本地；项目不保存你的会话尝试记录。

QUICK START

本地跑起来

前置：Python 3.12+、Node.js 18+。MySQL 和 AI Key 都是可选项。

  1. 克隆仓库获取完整前后端源码与文档。
  2. 启动后端安装依赖，复制 .env.example 为 .env，运行 main.py。
  3. 启动前端npm install 后 npm run dev，打开 localhost:5180。
  4. 开始定义输入一句话，观察预览，继续对话微调。
git clone https://github.com/wzdfk/WzdfkDiy.git
cd WzdfkDiy/backend

python -m venv .venv
# Windows: .\.venv\Scripts\Activate.ps1
source .venv/bin/activate

pip install -r requirements.txt
cp .env.example .env
python main.py

# 另开终端
cd ../frontend
npm install
npm run dev

MySQL 只用于「存档 / 档案」；不配置时仍可生成和导出。API Key 可在页面设置里填写，只保存在当前浏览器。

EXPORT FORMAT

导出即可交接

产物包包含 8 个文件。复刻新组件时，只需要前 4 个。

STYLE_PROMPT.md

风格规范正文，AI 首要读取。

base.css

:root 中的全部设计令牌。

style.css

组件样式规则与视觉签名。

preview.html

组件结构与类名示例。

其余 manifest.json、raw-llm.json、source-conversation.json、CHANGELOG.md 是溯源文件，便于审计，不必交给复刻 AI。
