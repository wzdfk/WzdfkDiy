# UIDiy Agent · 产品需求（PRD）

> 版本 v0.1 · 2026-11-18
> 一句话定位：把「UI 风格抽卡」工程化——用户用一句话定义风格，多轮对话打磨，最终产出可直接复刻该风格的三件套产物。

## 1. 背景与痛点

AI 辅助开发已普及，但 UI 风格是隐性知识：

- 用户不想千篇一律（AI 生成的界面长得都像）
- 用户说不清自己想要什么（"柔和一点"到底是哪个参数）
- 现状是反复向 AI"抽卡"：描述 → 生成 → 不满意 → 重抽，成本高、不可复现、产物之间互相打架

**本产品把这条路径变成产品流程**：模糊意图 → 结构化风格 → 所见即所得 → 多轮收敛 → 可复现产物。

## 2. 用户流程（核心闭环）

```
输入风格提示词（首次定义）
        │
        ▼
生成初始风格档案（tokens）
        │
        ▼
┌────────────────────────────┐
│  多轮对话优化（左）  ⇄  实时预览（右）  │
│  "再柔和一点" → token diff  │
└────────────────────────────┘
        │ 满意
        ▼
导出三件套：style.json / base.css + style.css / STYLE_PROMPT.md
```

参照流程（已人工验证跑通）：湖蓝 UI Kit → FOLD 折角设计系统的完整设计对话，见项目根目录 `fold-showcase.html` / `fold-design-system.css`。

## 3. 核心产物：三件套（一体三面）

三个产物同源于一份 **风格 Tokens（唯一事实来源）**，由系统派生，保证永不互相矛盾：

| 产物 | 形态 | 用途 |
|---|---|---|
| `style.json` | 结构化风格档案 | 机器可复现的事实源：色彩 8 级、圆角策略、投影类型、动效曲线等全部维度 |
| `base.css` + `style.css` | 模板渲染的样式文件 | 直接引入项目使用；AI 读 json+css 可按同一规范扩展新组件 |
| `STYLE_PROMPT.md` | 自然语言复原提示词 | 喂给任意 AI 的人话版风格描述 + 扩展组件的操作说明 |

**验收标准（复刻测试）**：用户把三件套发给一个新的 AI 会话，要求其按风格新增一个组件（如 Tabs），产出风格应与预览一致。这是产品的北极星指标。

## 4. 功能需求

### V0（无 AI，先跑通产物链）

- F1 单页 Studio：左侧对话输入区 + 右侧实时预览（分栏）
- F2 预览组件五件套（见 `效果验证组件.md`）：Button、Input、Toast、Card、Dropdown；Toast/Dropdown 做成可触发演示（动效是核心价值）；另加 Badge/Tag 小件
- F3 维度控制面板（V0 阶段的"假对话"：面板即对话）：调任意 token 维度实时生效
- F4 tokens → base.css / style.css / STYLE_PROMPT.md 生成与导出（zip 下载）
- F5 风格档案保存 / 载入（本地文件）

### V1（接入 AI）

- F6 提示词 → 初始 tokens（解析维度：色彩、形状、投影、动效、质感、字体…）
- F7 对话 → token diff：模糊指令（"柔和/硬朗/通透/敦实"）经风格词典映射为具体维度修改，只动相关维度，其余不动
- F8 复刻自检：导出前用提示词反推 tokens 与当前档案比对，给出一致度报告

### 后续（不承诺）

- 效果图导出截图（html2canvas）
- 风格库 / 收藏 / 分享
- 暗色模式派生
- 组件库扩展（表格、表单、导航）

## 5. 非目标（明确不做）

- 不做完整组件库（只做风格验证所需的组件集）
- 不做可视化拖拽布局工具（只管风格，不管页面结构）
- V0 不接 LLM（接口预留，架构不变）

## 6. 关键产品决策（已确认）

| 决策项 | 结论 |
|---|---|
| 产品形态 | 独立 Web 应用 |
| 技术栈 | Vue3 + Pinia + Router + axios + Naive UI / Python FastAPI |
| 效果图 | 右侧实时预览即效果图（所见即所导）；截图导出后置 |
| 导出 | 支持文件导出，产物可直接复刻风格（json + css 发给 AI 可复刻） |
| 预览与产物关系 | 预览直接加载后端生成的真实 CSS，所见 = 所导 |
| 本产品自身 UI | 使用自家 FOLD 折角设计系统（自举/dogfooding，见 fold-design-system.css） |
