# F8 复刻自检报告

> 2026-11-18 · 北极星指标验证：「三件套发给一个新 AI，能复刻出同款才算合格」

## 测试方法

1. 从 tokens（FOLD v1.0）生成三件套导出到 `backend/output/f8-export/`
2. 启动一个**全新 AI 会话**，只给 4 个文件（STYLE_PROMPT.md / style.json / base.css / style.css），不给任何项目上下文
3. 要求它按风格指南**扩展两个从未见过的组件**：Switch 开关、Tabs 标签页
4. 对产物 `replica.html` 做结构化签名核查

## 核查结果：9/9 通过

| 检查项 | 结果 |
|---|---|
| 正确引用 base.css / style.css，新组件 CSS 内嵌 | ✅ |
| 圆角引用 `var(--fd-r-*)` 档位 | ✅ |
| 无四角全圆（折角签名保持） | ✅ |
| 投影全部实色偏移（无模糊阴影） | ✅ |
| 动效走 `--fd-dur` + `--fd-ease-pop`（180ms 回弹） | ✅ |
| 焦点环虚线 | ✅ |
| 颜色零写死，全部 var 引用 | ✅ |
| hover = lift 位移签名 | ✅ |
| active = press 位移签名 | ✅ |

## 结论

**F8 通过**。新 AI 在零上下文条件下，仅凭三件套就复刻出了签名完整的风格扩展组件：
折角圆角、偏移实心投影、虚线焦点环、回弹动效四个签名特征全部保持，且没有写死任何与 style.json 冲突的值。

关键支撑（本轮溯源化改造的功劳）：
- style.json 的 `components.*` 组件盒模型字段 + CSS 里的 `@token` 溯源注释，让新 AI 能读出「每个值从哪来、扩展时该引哪个变量」
- 复刻件 `replica.html` 可直接在浏览器打开验证视觉效果

## 遗留观察

- Switch 滑块用了手写 6px 小折角而非变量档位（sm 8px 对滑块偏大）——属合理微调，不破坏签名；后续 tokens 可考虑增加 `radius.xs` 档位
- 扩展提示词里建议补一句「新增组件的盒模型字段应回写 style.json components 区」，让档案可持续沉淀
