# UIDiy Agent · 技术方案

> 版本 v0.1 · 2026-11-18
> 配套文档：`产品需求.md`（需求与决策）、`效果验证组件.md`（预览组件清单）

## 1. 总体架构

```
提示词 ──解析──▶ 风格 Tokens（唯一事实来源）──派生──▶ base.css / style.css / STYLE_PROMPT.md
                     │
                     └──注入──▶ 右侧预览 iframe（加载真实生成的 CSS）
```

**核心不变量**：全系统只有一份 tokens 事实源。

- CSS 与提示词均由后端从 tokens 模板渲染，三件套永不打架
- 预览 iframe 直接加载后端生成的真实 CSS（通过 postMessage 注入 / srcdoc），不是前端另画一份 → **所见即所导**
- 任何对话修改 = tokens 的 diff，落库后全链路自动刷新

## 2. 技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| 前端 | Vue3 + Vite + TypeScript | SPA |
| 状态 | Pinia | `style` store 持有 tokens，全局唯一 |
| 路由 | Vue Router | `/studio`（主页面）、`/about` |
| 请求 | axios | 调 FastAPI |
| 组件库 | Naive UI | 控制面板/表单等外壳组件（预览区组件不用它，预览必须用生成的 CSS） |
| 后端 | FastAPI + Pydantic v2 | tokens schema 校验、渲染、导出 |
| 模板 | Jinja2 | tokens → CSS / STYLE_PROMPT.md |
| LLM | adapter 模式（先 stub） | `llm.py` 定义接口，V1 接 API 只填实现 |

## 3. 核心：风格 Tokens Schema（Pydantic）

```python
class StyleTokens(BaseModel):
    meta: Meta          # name / version / created
    color: Color        # accent 8级(50..700) / ink(900,600,400) / paper / surface
                        # status: ok, warn, danger, info
    shape: Shape        # radius_strategy: fold | uniform | asymmetric
                        # radius: {lg, md, sm} 各为四角值
    line: Line          # border_width(1.5) / border_style / focus_style(dashed|solid|glow)
    elevation: Elev     # type: offset-solid | soft-blur | layered
                        # levels: {e1,e2,e3}，shadow_color
    motion: Motion      # duration(180ms) / easing / hover(lift|press|tilt) / active(press|none)
    type: TypeScale     # font_stack / display_size,weight,tracking / label_style
    spacing: Spacing    # 4pt 网格倍数
```

设计原则：维度有限且可枚举（风格词典的前提）；每个维度都有默认值；schema 版本化（`meta.version`），后续加字段向后兼容。

## 4. 生成器（core/）

| 模块 | 输入 → 输出 | 说明 |
|---|---|---|
| `css_gen.py` | tokens → `base.css` + `style.css` | Jinja2 模板。base = `:root` 变量 + reset；style = 组件类（fd-* 风格的通用类，前缀可配置） |
| `prompt_gen.py` | tokens → `STYLE_PROMPT.md` | 人话版风格描述 + "按本档案扩展组件"的操作说明，模板渲染 |
| `dict_style.py` | 模糊词 → token diff | 风格词典（V0 先内置规则表）："柔和" → 投影改 soft-blur + 边框减细 + 时长放缓；"硬朗" → offset-solid + 边框加粗 + 圆角减小 |
| `llm.py` | prompt/messages → tokens / diff | adapter 接口：`parse_prompt()` `chat_diff()`。V0 stub 返回词典结果 |

**风格词典是"不抽卡"的关键**：用户说"再柔和一点"，映射为 3~5 个维度的定向修改，其他维度不动 → 收敛快、可预期。

## 5. API 设计（FastAPI）

```
POST /api/style/parse        # 提示词 → StyleTokens（V0: 词典规则；V1: LLM）
POST /api/style/chat         # {tokens, message} → {tokens', diff, reply}（对话轮次）
POST /api/style/export       # tokens → zip(style.json, base.css, style.css, STYLE_PROMPT.md)
GET  /api/style/preview-css  # tokens → 生成的 css 文本（预览 iframe 拉取/注入用）
GET  /api/health
```

diff 返回结构：`[{path: "elevation.type", from: "soft-blur", to: "offset-solid", reason: "更硬朗"}]`——前端聊天面板直接把 diff 渲染成对话气泡，用户能看清"这句话改了什么"。

## 6. 前端结构

```
frontend/src/
├─ stores/style.ts            # Pinia：tokens + diff 历史 + undo
├─ api/style.ts               # axios 封装
├─ views/StudioView.vue       # 左右分栏（可拖拽分隔条）
├─ components/
│  ├─ chat/ChatPanel.vue      # 消息流（含 diff 卡片）+ 输入框
│  ├─ panel/TokenPanel.vue    # 维度控制（Naive UI 表单），与对话共用 store
│  └─ preview/StylePreview.vue# iframe + postMessage，注入 /preview-css 返回的真实 CSS
│  └─ preview/preview-doc/    # 预览文档结构：五组件 + Badge（纯 HTML，按 docs 清单）
```

预览要点：

- iframe 内是固定的演示文档（五组件 + 触发式 Toast/Dropdown 演示 + Badge）
- 样式完全来自注入的生成 CSS，预览组件**不写死任何样式值**
- tokens 变更 → 调 preview-css → iframe 重注入，过渡动画由 CSS transition 自然呈现

## 7. 本产品自身 UI：FOLD 折角设计系统（自举）

Studio 自身界面直接采用项目根目录的 `fold-design-system.css`（FOLD v1.0）：折角圆角、偏移实心投影、硬边细线+虚线焦点环、180ms 回弹动效、暖纸色底。

- 自举的双重价值：产品吃自己的狗粮验证风格通用性；Studio 即 FOLD 的活广告
- 实现方式：Naive UI 通过主题变量对齐 FOLD tokens；对话气泡、面板、按钮套 `fd-*` 类
- 预览区与 Studio 区在视觉上要有明确区隔（预览是"作品"，Studio 是"工作台"）

## 9. 里程碑

| 阶段 | 内容 | 验收 |
|---|---|---|
| M1 后端核心 | tokens schema + css_gen/prompt_gen + export API | 纯 Python：输入 FOLD tokens → 产出与 fold-design-system.css 同气质的三件套 |
| M2 前端 Studio | 五组件预览 + 维度面板实时调 | 拖滑杆，预览即时变化；面板与预览共享 tokens |
| M3 对话打通 | ChatPanel → dict_style → token diff → 刷新 | 输入"再柔和一点"，预览定向变化，对话里显示 diff 卡片 |
| M4 导出与接入 | 三件套 zip 下载 + 复刻自检 + llm.py 预留 | 导出的 css 引入新项目即得同款；接 LLM 只填 stub |

## 10. 风险与对策

| 风险 | 对策 |
|---|---|
| 提示词复原度不足 | F8 复刻自检（tokens 反推比对）+ STYLE_PROMPT.md 里附结构化档案 |
| 模糊指令映射歧义 | 风格词典维护成数据文件（可热更）；低置信度时反问用户二选一 |
| 生成 CSS 质量漂移 | 模板固定骨架 + tokens 只填值；快照测试锁住输出格式 |
| Naive UI 与 FOLD 风格打架 | Naive UI 只用于工作台外壳；主题变量对齐 FOLD tokens |
