1. **Button 按钮**
承载主色、圆角、hover / 点击动效、禁用态，整套 UI 的主色调、轻重感、交互反馈全靠它定调。是风格最核心的载体。
2. **Input 输入框**
高频出现，决定边框样式、焦点高亮、内边距、圆角、提示文字、激活态的高亮线条。它定义了你这套 UI 是纤细精致，还是厚重敦实。
3. **Toast 轻通知**
代表弹窗类的基础气质：阴影、圆角、配色、进出动画、透明度。toast 是无阻断的轻反馈，能直观体现柔和 / 锐利、通透 / 实底的风格倾向。
4. **Card 卡片**
页面布局容器，是承载所有内容的骨架。圆角、阴影、边框、内边距，决定页面整体留白、层次感。很多页面都是由卡片堆出来的，它奠定页面基础调性。
5. **Dropdown 下拉菜单**
兼具触发器 + 悬浮弹出面板，同时包含按钮、面板、选项 hover 态、分割线。一个组件同时覆盖触发控件、浮层容器、列表项三种样式，风格延展性很强。
